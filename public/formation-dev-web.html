Programme

Ce que vous allez apprendre

Un cursus structuré en 4 blocs progressifs, du fondamental au professionnel, avec l'IA comme fil conducteur.

Bloc 01

Fondamentaux du Web

  • HTML5, CSS3 & design responsive
  • JavaScript ES6+ & TypeScript
  • Git & GitHub, workflow professionnel
  • Accessibilité (WCAG) & SEO
Bloc 02

Front-end Avancé

  • React.js & composants réutilisables
  • State management (Redux, Zustand)
  • Next.js & rendu côté serveur
  • Tests unitaires & d'intégration
Bloc 03

Back-end & APIs

  • Node.js & Express
  • Bases de données SQL & NoSQL
  • API REST & GraphQL
  • Authentification & sécurité
Bloc 04

IA & DevOps

  • Intégration d'APIs IA (OpenAI, etc.)
  • Docker & containerisation
  • CI/CD & déploiement cloud
  • Projet professionnel de fin d'études
Stack technique

Les technologies que vous maîtriserez

HTML / CSS JavaScript TypeScript React.js Next.js Node.js Express.js SQL / PostgreSQL MongoDB Git & GitHub Docker APIs IA
