Programme

Ce que vous allez apprendre

Un cursus en 4 blocs progressifs : les fondations Full Stack en première année, puis une spécialisation avancée en IA en deuxième année.

Bloc 01

Fondations Web Full Stack

  • HTML, CSS, JavaScript ES6+, TypeScript
  • React.js & Next.js — applications modernes
  • Node.js, FastAPI, bases de données SQL/NoSQL
  • Git, Docker, CI/CD — workflow professionnel
Bloc 02

Python & Data Science

  • Python avancé — structures, POO, async
  • NumPy, Pandas, Scikit-learn
  • Mathématiques pour l'IA (algèbre, stats)
  • Visualisation & analyse exploratoire
Bloc 03

LLMs & Agents IA

  • Deep Learning avec PyTorch & TensorFlow
  • Transformers, fine-tuning & prompt engineering
  • LangChain, LlamaIndex — agents & RAG
  • APIs IA (OpenAI, Anthropic, Mistral, HuggingFace)
Bloc 04

MLOps & Intégration Systèmes

  • Déploiement de modèles (FastAPI, Triton)
  • MLflow, DVC — suivi d'expériences
  • Architecture micro-services avec IA embarquée
  • Projet professionnel de fin d'études
Stack technique

Les technologies que vous maîtriserez

Python JavaScript / TypeScript React.js Next.js Node.js FastAPI PyTorch TensorFlow LangChain LlamaIndex OpenAI / Anthropic API HuggingFace SQL / PostgreSQL MongoDB Docker & Kubernetes MLflow / DVC Git & GitHub
Semaine par semaine

Programme détaillé — 26 semaines

Retrouvez le contenu précis de chaque semaine de formation sur les 2 années du cursus.

Semaine 1 — Environnement & bases du web

Découverte & installation (1 jour, 7h)

Fonctionnement du web (client/serveur, HTTP). Installation de l'environnement (VS Code, Node.js, Python, Git).

HTML & CSS (4 jours, 28h)

Structure HTML5 sémantique, CSS (flexbox, grid, animations). Approche « mobile first », accessibilité et normes WCAG.

Semaine 2 — JavaScript & Git

JavaScript ES6+ (3 jours, 21h)

Variables, fonctions, closures, manipulation du DOM, fetch API, async/await.

Versionnage avec Git & GitHub (2 jours, 14h)

Branches, pull requests, workflow professionnel, revue de code.

Semaine 3 — Python niveau I

Fondamentaux Python (5 jours, 35h)

Syntaxe, types, structures de données, fonctions, modules. Compréhensions de listes, générateurs, décorateurs. Environnements virtuels et gestion des dépendances avec pip / Poetry.

Semaine 4 — Python niveau II & POO

Programmation orientée objets (5 jours, 35h)

Classes, héritage, polymorphisme, interfaces. Design patterns courants. Programmation asynchrone (asyncio) en Python.

Semaine 5 — React.js

Front-end moderne avec React (5 jours, 35h)

Composants fonctionnels, hooks, gestion de l'état (useState, useContext), routage avec React Router. Consommation d'APIs REST.

Semaine 6 — Mathématiques pour l'IA & SEO

Mathématiques appliquées (3 jours, 21h)

Algèbre linéaire (vecteurs, matrices, produit scalaire), probabilités et statistiques descriptives. Applications directes aux algorithmes d'apprentissage automatique.

Référencement & UX (2 jours, 14h)

Optimisation SEO : métadonnées, accessibilité, performances. Notions de design et d'ergonomie pour des interfaces orientées utilisateur.

Semaine 7 — Back-end avec FastAPI

FastAPI & APIs REST (5 jours, 35h)

Création d'APIs REST avec FastAPI, validation des données avec Pydantic, authentification JWT, documentation automatique avec Swagger.

Semaine 8 — Bases de données

SQL, PostgreSQL & SQLAlchemy (3 jours, 21h)

Modélisation relationnelle, requêtes complexes, ORM SQLAlchemy. Connexion depuis Python et FastAPI.

MongoDB & données non-structurées (2 jours, 14h)

Bases NoSQL pour stocker embeddings et documents IA. Introduction à Chroma et bases vectorielles.

Semaine 9 — Data Science & Scikit-learn

NumPy, Pandas, Matplotlib (2 jours, 14h)

Manipulation de données tabulaires, analyse exploratoire, visualisation.

Machine Learning avec Scikit-learn (3 jours, 21h)

Régression, classification, clustering. Pipeline ML, validation croisée, métriques d'évaluation.

Semaine 10 — Docker & DevOps

Conteneurisation avec Docker (5 jours, 35h)

Création d'images, Docker Compose, réseaux entre conteneurs. Déploiement d'une application web + API Python dans un stack Docker.

Semaine 11 — Introduction aux LLMs

Comprendre les grands modèles de langage (5 jours, 35h)

Architecture Transformer, tokenisation, embeddings. Utilisation des APIs OpenAI et Anthropic. Prompt engineering fondamental : zero-shot, few-shot, chain-of-thought.

Semaine 12 — Intégration IA dans une application web

Projet fil rouge IA (3 jours, 21h)

Conception d'une interface React qui interagit avec une API FastAPI intégrant un LLM. Gestion du streaming, historique de conversation, affichage Markdown.

Communication professionnelle (2 jours, 14h)

Présentation de projets techniques, rédaction de documentation, personal branding et LinkedIn.

Semaine 13 — Mémoire & projet de fin d'année

Définition de la problématique, structuration du mémoire. Rendez-vous individuels, attendus pédagogiques et modalités d'évaluation de l'année 1.

Semaine 14 — Deep Learning avec PyTorch

Réseaux de neurones (5 jours, 35h)

Tenseurs, autograd, construction de réseaux avec PyTorch. Rétropropagation, fonctions d'activation, optimiseurs (Adam, SGD). Entraînement sur GPU.

Semaine 15 — Vision & NLP classique

Réseaux convolutifs & traitement du langage (5 jours, 35h)

CNN pour la vision par ordinateur. RNN, LSTM. Tokenisation, embeddings Word2Vec/GloVe. Transition vers l'architecture Transformer.

Semaine 16 — Fine-tuning & HuggingFace

Adapter un modèle pré-entraîné (5 jours, 35h)

Écosystème HuggingFace : Transformers, Datasets, Tokenizers. Fine-tuning supervisé (SFT), LoRA / QLoRA pour des modèles légers. Évaluation et benchmarks.

Semaine 17 — Prompt Engineering avancé

Maîtrise des LLMs (5 jours, 35h)

Techniques avancées : ReAct, Tree-of-Thought, function calling. Évaluation des sorties LLM. Utilisation de Mistral, Llama, Gemini et Claude. Sécurité et guardrails.

Semaine 18 — RAG & bases vectorielles

Retrieval-Augmented Generation (5 jours, 35h)

Architecture RAG complète : indexation, chunking, embeddings, recherche sémantique. Bases vectorielles : Chroma, Pinecone, Weaviate. Implémentation avec LlamaIndex.

Semaine 19 — Agents IA & LangChain

Systèmes agentiques (5 jours, 35h)

Architecture d'agents autonomes avec LangChain : outils, mémoire, planification. Multi-agents avec CrewAI et AutoGen. Intégration d'APIs externes comme outils d'agent.

Semaine 20 — MLOps & suivi d'expériences

Cycle de vie des modèles (5 jours, 35h)

Suivi d'expériences avec MLflow, versionnage des données avec DVC. Registre de modèles, déclenchement automatique de ré-entraînement. Détection de dérive (data drift).

Semaine 21 — Déploiement de modèles

Mise en production IA (5 jours, 35h)

Exposition de modèles via FastAPI. Optimisation inférence : ONNX, quantification. Déploiement sur cloud (AWS SageMaker, GCP Vertex AI, Azure ML). Monitoring en production.

Semaine 22 — Architecture micro-services IA

Systèmes distribués avec IA embarquée (5 jours, 35h)

Découpage en services : API Gateway, service d'inférence, service RAG, interface utilisateur. Kubernetes pour l'orchestration. Communication inter-services avec gRPC et files de messages (Redis, RabbitMQ).

Semaine 23 — Droit, éthique & RGPD

IA responsable (3 jours, 21h)

Cadre légal de l'IA en Europe (AI Act), RGPD et données personnelles. Biais algorithmiques, explicabilité (SHAP, LIME), sécurité des modèles.

Santé au travail (2 jours, 14h)

Risques professionnels, gestion du stress, équilibre vie pro/perso pour les développeurs.

Semaine 24 — Projet professionnel

Développement du projet de fin d'études (5 jours, 35h)

Conception et développement d'une solution IA complète intégrée dans une application full stack. Accompagnement individuel, revues de code et jalons intermédiaires.

Semaine 25 — Finalisation & documentation

Mémoire & documentation technique (5 jours, 35h)

Rédaction du mémoire, documentation du projet, préparation des supports de soutenance. Simulations d'oral devant les formateurs.

Semaine 26 — Soutenance

Présentation devant jury (5 jours, 35h)

Soutenance du mémoire et du projet professionnel devant un jury de professionnels. Évaluation des compétences en entreprise par le maître d'apprentissage.

Admission, objectifs, financement et plus

Comment nous rejoindre ?

  • Remplir le formulaire de candidature avec un CV à jour
  • Participer à la réunion d'information
  • Trouver une entreprise d'accueil pour l'alternance (notre équipe de chargés de relations entreprises vous accompagne)

Délai d'accès & promotions

15 jours à 1 mois — Une rentrée tous les 2 à 3 mois — Promotions de 15 à 20 étudiants.

Niveaux d'entrée

1ère année (Bac+4) — niveau Bac+3 ou certification RNCP niveau 6 en lien avec l'informatique, le développement logiciel, la data ou l'e-commerce.

2ème année (Bac+5) — niveau Bac+4 ou titre RNCP niveau 6 en lien avec le développement web, la data science ou l'intelligence artificielle.

Objectifs de la formation

  • A1 — Concevoir et développer des applications web full stack intégrant des composants d'intelligence artificielle
  • A2 — Sélectionner, configurer et fine-tuner des modèles d'IA adaptés aux besoins métier
  • A3 — Déployer et maintenir des solutions IA en production dans des architectures micro-services
  • A4 — Concevoir des pipelines MLOps pour le suivi, la surveillance et l'amélioration continue des modèles
  • A5 — Intégrer des agents IA et des systèmes RAG dans des applications d'entreprise

Comment financer la formation ?

Pour l'étudiant en alternance

Art. L6211-1 : « La formation est gratuite pour l'apprenti et pour son représentant légal. » En alternance, vous ne payez aucun frais de scolarité et percevez un salaire mensuel.

Pour l'entreprise d'accueil

Le tarif est aligné sur le montant de prise en charge de l'OPCO concerné. Zéro reste à charge pour les entreprises du secteur privé.

Tarif de la formation = montant de la prise en charge OPCO (jusqu'à 16 000 € par an maximum pour un Bac+5).
